# Character art

Character definitions in `veilbound/assets/data/anime_bedriegers_bedrogen.json` store project-root-relative image paths here. Portraits are organized into series subfolders such as `Naruto`, `My Hero Academia`, `Hunter x Hunter`, `One Piece`, and `Dragon Ball`. Set each character's `image` value to its project-root-relative path. PNG and JPG images are supported; missing or unreadable files use the generated fallback portrait.
