# Sounds

Enable flag and volume are configured in `config/settings.json`; which file plays is fixed per game state in `veilbound/client/audio.py`. `Intro_Lobby_music.mp3` plays from launch and throughout the main lobby (it never restarts while navigating lobby screens), `Loading_into_match_music.mp3` plays while entering a match, `Game_Music.mp3` plays throughout active gameplay (never in the lobby or loading screens), `Options_Menu_Music.mp3` plays while the in-game options/pause menu is open — game music fades out and resumes when gameplay returns — and `Bye_Bye.mp3` plays once on shutdown before the application exits. Only one track plays at a time. Character-specific sounds under `Abillity_Sfx/Ability_Resolution/` play when the corresponding ability successfully resolves. `New_row/New Row sfx.mp3` plays when scoring advances to another row, and `card_place/Card Place Sfx.mp3` plays once when a card is placed.
