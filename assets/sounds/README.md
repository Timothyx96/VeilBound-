# Sounds

Sound paths, volume, loop, and enable flags are configured in `config/settings.json`. `Background_music/Background_Music.mp3` plays continuously by default. The seven files under `Abillity_Sfx/` are selected uniformly for card reveals, `New_row/New Row sfx.mp3` plays when scoring advances to another row, and `card_place/Card Place Sfx.mp3` plays once when a card is placed.
